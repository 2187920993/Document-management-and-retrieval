# 文件服务接口约定

文档编号：API-032  
版本：1.2  
维护团队：文件服务组  
更新日期：2026-09-15  
适用系统：星桥协作平台

## 1. 文件与索引分别记录

文件保存成功表示原始字节已经持久化，并产生 documentId。能否被正文检索或语义检索找到，由 indexStatus 表示。两种状态不能合并成一个布尔字段。

indexStatus 取值为 pending、processing、ready、failed 或 not_supported。PDF 在基础部署中可以保存和下载，未启用提取器时返回 not_supported。失败的索引任务保留可读的原因与重试入口，不删除已经保存的文件。

## 2. 创建上传

POST /api/v1/documents 接收 multipart/form-data，字段包括 file、categoryId 和可选的 tags。演示环境单文件上限为 20 MiB，即 20 × 1024 × 1024 字节；该数值是本项目配置，不代表通用行业限制。

客户端为一次上传生成 Idempotency-Key。服务端在同一用户范围内记住该键与上传请求摘要：相同键、相同内容返回同一文档；相同键、不同内容返回 409，提示生成新请求。网络失败后重试应复用原键，主动再上传一个新版本则使用新键。

成功保存后返回 201，响应示例：

```json
{
  "documentId": "doc_demo_238",
  "name": "上线说明.md",
  "sizeBytes": 2486,
  "storageStatus": "stored",
  "indexStatus": "pending",
  "archived": false
}
```

上述标识仅用于说明格式。生产中的下载地址必须由服务端根据记录生成，不接受客户端传入任意磁盘路径。

## 3. 查询、下载与调整归属

GET /api/v1/documents 支持 q、categoryId、archived、page 和 pageSize。默认只返回未归档文档。categoryId 是精确分类筛选，不能因为搜索词相近而混入其他分类。

GET /api/v1/documents/{id} 返回详情；GET /api/v1/documents/{id}/download 返回原始文件。修改归属使用 PATCH /api/v1/documents/{id}。文件名保留用户可读形式，实际存储键与显示名称分离，防止同名文件互相覆盖。

## 4. 索引重试

POST /api/v1/documents/{id}/index-retry 为 failed 文档重新排队。已在 pending 或 processing 的任务不重复创建，返回当前任务状态。重复执行同一任务不得产生重复片段，索引写入使用文档与内容版本作为关联标识。

原文件丢失、暂时无法连接模型服务和不支持文件格式应给出不同原因。对暂时性失败设置有限次数的自动重试，超出后交给人工重试，避免无限消耗资源。

## 5. 常用错误

400：请求字段不完整或分类无效；404：文档不存在；409：幂等键对应的内容冲突或状态不允许；413：文件超过上传上限。接口不返回服务器磁盘路径、内部凭证或完整堆栈。

正文和语义搜索都应检查 archived 状态。归档与恢复的产品规则见 POL-006，索引异常的排查案例见 INC-20260921。
